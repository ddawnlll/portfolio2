# Yusuf Karaca — Portfolio

A warm, editorial portfolio for software applications in Germany. The site is built with React, TypeScript, Three.js and Motion; its contribution calendar is generated from the GitHub GraphQL API with an explicit snapshot date.

- Live site: <https://ddawnlll.github.io/portfolio2/>
- Turkish build guide: <https://ddawnlll.github.io/portfolio2/rehber/>
- CV: <https://ddawnlll.github.io/portfolio2/Yusuf-Karaca-CV.pdf>

## Local development

```bash
npm install
npm run dev
```

To refresh GitHub data, provide `GH_TOKEN` or `GITHUB_TOKEN` and run `npm run data`.
